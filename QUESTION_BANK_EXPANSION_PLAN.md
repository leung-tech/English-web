# P1–P6 Question-Bank Expansion Plan

## Audit summary

The existing platform already contains core banks for grammar, reading, listening, vocabulary, sentence building, proofreading, writing planning and speaking. It also includes specialised senior modules for listening vocabulary, listening quick checks, oral presentations, role-play, advanced reading and writing-model support. However, many core banks provide only three to six activities per level, which limits repeat practice.

## Expansion targets

| Category | Current pattern | Expansion applied per relevant year level |
|---|---:|---:|
| Vocabulary & spelling | Scope-led word checks | Add 6 topic words and contextual multiple-choice items |
| Grammar & patterns | 6 questions | Add 4 grammar questions |
| Reading comprehension | 3 passages × 2 questions | Add 2 original passages × 2 questions |
| Key detail hunter | Derived from reading bank | Automatically receives the added reading questions |
| Sentence builder | 6 sentence sequences | Add 4 sentence-order tasks |
| Proofreading | 6 corrections | Add 4 correction tasks |
| Writing planner | 3 prompts | Add 3 new prompts |
| Speaking | 2–3 prompts or activities | Add 3 foundational/senior prompts or one extra senior oral activity |
| P1–P3 listening | 4 items | Add 4 replayable listening items |
| P4–P6 listening | 2 scripts × 4 questions | Add 1 script × 4 questions |
| P1–P3 phonics/story game | 6 questions | Add 4 game questions and 3 matching cards |
| P4–P6 listening vocabulary | 8 flashcards | Add 4 flashcards |
| P4–P6 listening quick check | 6 questions | Add 4 checks |
| P4–P6 role-play | 2 dialogues | Add 1 dialogue |
| P4–P6 advanced reading | 2 passages × 2 questions | Add 1 original passage × 2 questions with model analysis |

## Content controls

All additions use original, age-appropriate English and retain immediate Traditional-Chinese support. Audio-backed activities use the website’s existing browser speech playback. Question selection continues to randomise options and preserve local progress and review behaviour.
