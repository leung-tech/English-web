# Writing Support Feature Design

## Resource flow

The existing P4–P6 high-score model page will gain a second learning layer immediately below the model composition. Pupils first read the complete model, then choose one of three compact support panels:

| Panel | Learning objective | Pupil action |
|---|---|---|
| **Common mistakes · 常見錯誤** | Notice frequent genre-specific errors in format, tense, content development or tone | Compare a weak sentence with a corrected version and read the correction tip |
| **Vocabulary builder · 詞彙擴展** | Move from basic words to precise topic vocabulary | Replace simple words with stronger alternatives, then use one in a personal sentence |
| **Sentence patterns · 高分句式** | Adapt reusable structures without copying whole model paragraphs | Fill the brackets with their own content and create an original sentence |

A model-specific **proofreading routine · 五步改文法** follows the panels. It directs pupils to check format, task points, grammar, punctuation and word choice in a fixed order.

## Information hierarchy

The model composition remains the largest element. The new support layer uses an expandable tab interface beneath it, so the page avoids presenting every explanation at once. Each selected panel uses a recognisable colour: coral for corrections, blue for vocabulary and leaf green for sentence patterns. Traditional Chinese sits under each English heading and tip as immediate support; the English examples remain prominent.

## Exercise design

Vocabulary practice is deliberately short and contextual. A pupil sees a basic word in a model’s topic, three stronger alternatives and a prompt to write an original replacement sentence. Sentence patterns are stored as adaptable frames, such as `First, [suggestion]. This would [benefit].` The wording makes it clear that bracketed parts must be changed, which discourages rote copying.

## Assessment alignment

Every correction and practice item is linked to an observable writing quality: task fulfilment, content development, organisation, language accuracy, or vocabulary and variety. The feature is a learning scaffold, not a claim about an official school-specific scoring scheme.
