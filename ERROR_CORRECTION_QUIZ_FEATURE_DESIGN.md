# Error-Correction Quiz Feature Design

## Placement

The quiz is the fourth panel in the existing **Build from the model · 從範文延伸** area, after Common mistakes, Vocabulary builder and Sentence patterns. It is displayed as **Quick correction quiz · 快速改錯小測** and is available for each of the six P4–P6 genre models.

## Interaction sequence

| Step | Learner experience | Feedback |
|---|---|---|
| 1 | Read a weak sentence and the concise correction question | Shows the targeted grammar or genre focus |
| 2 | Select one of three corrected-sentence options | The selected answer is visibly marked |
| 3 | Check the answer | Immediate bilingual explanation confirms the grammar point or reveals the corrected sentence |
| 4 | Move to the next question | Progress indicator shows the question number in the three-question round |
| 5 | Complete the round | A short accuracy summary reinforces that the result is practice feedback, not an official assessment mark |

## Preview path

The completed P4–P6 writing-support interface will be inspected through the following sequence:

1. **P4 informal email**: high-score model, scoring panel, common-mistake cards, quiz.
2. **P5 formal email**: vocabulary builder, sentence-pattern cards and quiz feedback.
3. **P6 proposal**: full model, editing guidance, sentence patterns and completed quiz state.
4. **P6 magazine article**: article-specific subject–verb, modal and linker corrections.

The visual design uses the existing model-library palette. Coral identifies a weak sentence, leaf green identifies a stronger correction, navy identifies the active answer, and the model’s scoring panel remains visible alongside the resource, preserving a coherent end-to-end writing-improvement flow.
