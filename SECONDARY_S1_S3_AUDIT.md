# Secondary English Studio: S1–S3 Baseline Audit

## Scope and curriculum direction

The current independent Secondary English Studio already separates S1–S2 learning from the P1–P6 interface. Its bilingual, original-practice and browser-local-progress approach should be retained as the S1–S3 system grows. The proposed expansion uses purposeful communication, learner independence, literary or imaginative reading, and critical thinking as design anchors, which are consistent with the Education Bureau's stated English Language Education direction.[1]

## Functional baseline and gaps

The current secondary page offers stage selection, four skill routes, replayable browser speech, immediate answer feedback, writing word-count self-checks, speaking model playback and browser-local completion counts. It correctly avoids claims of automated language-quality scoring.

| Current capability | Status | Expansion required |
|---|---|---|
| Grammar, vocabulary, reading and listening questions | Available as separate unit banks | Add mixed review, topic tags and skill-level progression across S1–S3. |
| Writing and speaking tasks | Available from S1 Core onward | Add genre ladders, source packs, reusable success criteria and saveable local drafts. |
| Role-play dialogue | Available only in S2 Action | Extend to S1 and S3 with reply checkpoints and practical communication contexts. |
| Progress tracking | One local completion total | Add local skill-, stage- and topic-level progress summaries without accounts or uploads. |
| S3 curriculum path | Missing | Add three progressively demanding S3 units plus an S3 readiness review. |
| Editor structure | Separate data files used by the secondary entry page | Preserve file-per-unit data architecture and document the required schema. |

## Design conclusion

The next build should create a coherent three-year learning ladder rather than merely adding isolated questions. S1 will secure transition, school communication and sentence accuracy; S2 will apply evidence, audience and comparative thinking; S3 will strengthen interpretation, source evaluation, formal response and secondary-school readiness. All new items will be clearly identified as original practice rather than official examination papers.
