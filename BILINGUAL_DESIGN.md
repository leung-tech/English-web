# Bilingual Design Direction

## Design objective

The refined interface presents **English as the learning target** and **Chinese as the learning support**. English labels appear first, so pupils continually encounter the correct subject vocabulary. A shorter Traditional Chinese translation directly below or beside each key label explains the purpose of the activity without competing with the target language.

> **English first for exposure; Chinese second for clarity.**

## Bilingual hierarchy

| Interface layer | English treatment | Chinese treatment |
|---|---|---|
| Skill routes | Large route title, such as “Read” | Compact support label, such as “閱讀理解” |
| Activity cards | English activity title and purpose | One-line explanation of the task and learning aim |
| Year scope | English category title and grade scope | Matching Chinese category title, explanations and key terms |
| Practice screen | Question and target language remain in English | Navigation, learning habit and feedback guidance are bilingual |
| Listening support | English replay labels and transcript | Chinese explanation of when and how to use them |

## Layout refinements

The home page uses a clearer three-level reading path: an editorial hero, four colour-coded skill cards and a focused practice board. Each card receives more consistent internal spacing, a distinct English title, a Chinese support label and a short bilingual description. The selected activity is given a dedicated action strip so that pupils can identify the next action immediately.

The year-scope page will distinguish **Vocabulary · 詞彙**, **Grammar & Patterns · 文法與句型**, **Reading & Writing · 閱讀與寫作**, and **Listening & Speaking · 聆聽與口語**. Scope topics will use compact English–Chinese chips, which makes the curriculum easier for parents and pupils to scan.

The practice screen will preserve English-only questions and answer options where appropriate. Its surrounding instructional interface will pair labels such as **Practice path · 練習進度**, **Good learner habit · 學習小提示**, and **Listen first · 先聽再答**, reducing uncertainty while protecting the integrity of the English exercise.

## Responsive behaviour

On narrow screens, bilingual labels wrap into clear two-line groups rather than becoming smaller or crowded. English remains visually stronger; Chinese uses a smaller muted type style with generous line-height. Controls retain a full-width, touch-friendly layout where needed.
